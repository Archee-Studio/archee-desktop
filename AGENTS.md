# archee-desktop

A [Tauri](https://tauri.app) window around Archee Studio: it hosts the web app and adds a draggable title bar, zoom keys and opening outside links in the browser.

## Commands

```sh
bun install
bun run build      # installer for this system, in src-tauri/target/release/bundle
```

Needs [Rust](https://rustup.rs) and [Bun](https://bun.sh).
